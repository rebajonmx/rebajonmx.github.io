# Rebajón MX · sistema automático de ofertas

Página de ofertas verificadas + videos diarios en Instagram, Facebook y TikTok. **Corre solo, gratis, 2 veces al día.**

| Quiero… | Dónde |
|---|---|
| Ver si todo está bien | **[ESTADO.md](ESTADO.md)** (🟢 / 🟡 / 🔴) |
| Ofertas nuevas sugeridas (lunes y jueves) | **[data/sugerencias.md](data/sugerencias.md)** |
| Agregar o quitar ofertas | **[data/links.txt](data/links.txt)** (una por renglón; guía en [MANUAL §3](docs/MANUAL.md)) |
| Pedir un video nuevo con una frase | **[contenido/pedido.txt](contenido/pedido.txt)** (con Gemini) |
| Crear o editar videos a mano | **[contenido/conceptos/](contenido/conceptos)** · guía: [docs/CONCEPTOS.md](docs/CONCEPTOS.md) |
| Cambiar marca, colores, campaña, hashtags | **[config/marca.json](config/marca.json)** |
| Instrucciones completas para personas | **[docs/MANUAL.md](docs/MANUAL.md)** |
| Contexto completo para una IA (Gemini, Jules, etc.) | **[AGENTS.md](AGENTS.md)** |
| **Estrategia para ganar seguidores (copiar y pegar)** | **[docs/MARKETING.md](docs/MARKETING.md)** |
| Plan de continuidad y crecimiento | **[docs/PLAN.md](docs/PLAN.md)** |
| Conseguir más seguidores (rutina diaria, textos listos, anuncios baratos) | **[docs/CRECIMIENTO.md](docs/CRECIMIENTO.md)** |
| Instrucciones listas para pegar en una IA gratis | **[docs/PROMPTS.md](docs/PROMPTS.md)** |
| Correr ahora o probar sin publicar | Pestaña **Actions** → "Rebajón MX automático" → **Run workflow** |

Herramientas (todas gratis): GitHub Actions (servidor y horario), Netlify (página), Buffer (publicación en redes),
API de Mercado Libre (datos de productos, opcional), Telegram (alertas, opcional), Gemini (ideas, opcional).
